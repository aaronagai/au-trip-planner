# Australia Trip Planner

Trip dashboard for Sydney & Melbourne, Nov 2026.

**Live preview:** https://aaronagai.github.io/au-trip-planner/

## Overview

- **Destination:** Sydney & Melbourne
- **Dates:** 6 Nov – 15 Nov 2026
- **Pax:** Aaron & Andrea

## Features

- Expense breakdown (flights, accommodation, food, transport, utilities)
- Donut chart and contribution split
- Budget progress bars
- Calendar view with travel and office leave modes
- Expandable detail tables for each category
